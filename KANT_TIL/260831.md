- 딥러닝 기초13-1
  - RNN은 이전 단계의 정보가 현재 단계의 연산에 영향을 미치는 순환 구조의 인공신경망이다.
  - 자연어, 음성, 시계열 데이터 등의 시퀀셜 데이터에 특화되어 있다.
  - 각 단계마다 이전 단계의 hidden state가 연산에 참여하고, 해당 단계의 hidden state가 연산되어 다음 단계의 연산에 참여하는 구조이다.
  - 순서가 중요한 데이터들을 시퀀스 데이터라고 한다.
  - 딥러닝에서 시퀀스 데이터를 `(batch_size, sequence_length, input_size)`의 형태의 텐서로 바궈서 처리한다.
    - `batch_size`: 한 번에 처리하는 샘플 수
    - `sequence_length`: 각 샘플 안의 시점/토큰 수
    - `input_size`: 각 시점이 가진 feature 수
  - PyTorch에서는 `batch_first=True`를 통해서 시퀀스 데이터를 사용한다.
  - hidden state는 직관적으로 현재 입력인 `x_t`와 직접 입력인 `h_{t-1}`을 사용해서 현재의 hidden state인 `h_t`를 만드는 것이다.
  - `현재 입력 + 이전 기억 -> 새로운 기억`의 형태로 볼 수 있다.
  - 물론 진짜로 합연산을 하는 것은 아니다.
  - RNN의 입력에 대해서 출력은 `output, h_n`으로 각각 전체 시점에 대한 hidden state와 마지막 시점의 hidden state이다.
  - 입력되는 값이 고정 길이, 무패딩, 1-layer, 단방향이라면 `output[:, -1, :]`은 `h_n[-1]`의 값과 같다.
  - 일반적인 `h_n`의 shape는 `(D*num_layers, batch, hidden_size)`이다.
  - `D`는 단방향일 때는 1, 양방향일 때는 2이며, `batch_first=True`는 input과 output의 차원 순서만 바꾼다.
  - 가변 길이의 경우 sequence_length가 가장 긴 샘플에 맞춰지고, 나머지는 `<PAD>`토큰으로 채워지게 된다.
  - 그 경우에 그 공간에 대한 hidden state는 의미없는 것이기 때문에 전체 hidden state들 중에서 유의미한 hidden state를 찾아야 한다.
- 딥러닝 기초13-2
  - RNN의 forward 결과로 나온 전체 hidden state 중에서 마지막 시점의 hidden state를 사용해서 예측을 수행해야 한다.
  - 전체 중의 마지막이 PAD가 아닌지 잘 골라야 한다.
- 딥러닝 기초13-3
  - RNN에는 장기 의존성이 있는데, 이는 현재 예측에 중요한 정보가 멀리 떠어져 있는 경우를 말한다.
  - RNN에서 계산을 하는 노드는 하나로, 시퀀스 길이가 100이어도 같은 노드를 100번 연산한 것이기 때문에 실제고 계산그래프에서 미분값은 전부 같다.
  - 그러면 grad를 계산하기 위해서 미분했을 때의 값이 1이하라면 누적 grad의 값이 점점 작아지고, 1보다 크면 점점 커져만간다.
  - 작아지는 쪽으로 향하면 경사 소실, 커지는 쪽으로 향하면 경사 폭주가 발생하는 것이다.
  - 경사 폭주의 경우에는 gradient clipping이라고 계속해서 작게 만들어가지만 결국 계속 커지는 방향으로 향하기 때문에 정답이 될 수는 없다.
- 딥러닝 기초13-4
  - LSTM은 RNN과 마찬가지로 하나의 셀이 반복해서 계산되는 방식이지만 hidden state 이외에도 cell state를 만들어내기도 하고, 그 방식이 4가지 게이트를 통해서 복잡하게 만들어진다.
  - 또한 정보를 곱하는 방식으로 추가하는게 아니라 더하는 방식으로 누적해가기 때문에 경사에 대해서 문제가 덜 발생하게 된다.
  - LSTM에 존쟇는 게이트들은 다음과 같다.
    - Forget Gate: 잊을 것을 결정
    - Input Gate: 기억할 것을 결정
    - Candidate Memory: 새로 기억할 후보
    - Output Gate: 출력할 것을 결정
  - Gate는 정보의 양을 조절하고, Candidate는 새로 저장할 후보를 만든다.
  - LSTM은 기존의 RNN의 오래된 기억은 잊혀져가는 장기 의존성을 해결하기 위해서 나온 모델로, hidden state가 현재와 가까운 기억을 담당하면 cell state는 오래 유지할 기억을 담게 된다.
  - 게이트는 기본적으로 활성화 함수가 시그모이드로 출력 값이 0~1이다.
  - candidate는 정보를 다양하게 표현해야하기 때문에 tanh로 -1~1사이의 값을 출력한다.
- 딥러닝 기초13-5
  - 기존의 RNN은 장기 기억에 대한 문제가 있고, 이를 해결하기 위해서 LSTM이 나왔다.
  - 그러나 LSTM 또한 시점에 대한 의존성 문제와 병렬 처리 불가에 대한 문제가 있다.
  - 이에 따라서 Transformer 모델로 연결되게 되었다.

## 왜 중요한가
- 시계열 데이터를 처리하기 위한 기본적인 방식과 어떤 경위로 Transformer 모델이 나오게 되었는지에 대한 배경을 알 수 있게 해주는 강의였다.

## 느낀점
- 오늘은 크게 직접 실습해보거나 하는건 없었고, 그저 이론적으로 배운 것들을 합치는 부분이 컸다.
- 하지만 시계열 데이터는 실습해보면 좋을거 같지만 아쉽게도 학습을 위한 데이터가 따로 있는것도 아니고 Transformer를 위한 중간다리라서 이 정도면 충분한거 같기도 하다.

```python
# 기준 CNN 모델 예제
import torch
import torch.nn as nn

class SmallCNN(nn.Module):
    """
    CIFAR-10 이미지 분류를 위한 작은 CNN baseline입니다.
    입력:  (N, 3, 32, 32)
    출력:  (N, num_classes)
    """
    def __init__(self, num_classes=10):
        super().__init__()

        self.features = nn.Sequential(
            # 첫 번째 block: RGB 3채널을 16채널 feature map으로 변환합니다.
            nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 32x32 -> 16x16

            # 두 번째 block: 16채널을 32채널 feature map으로 변환합니다.
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 16x16 -> 8x8
        )

        self.flatten = nn.Flatten()
        self.classifier = nn.Linear(32 * 8 * 8, num_classes)

    def forward(self, x):
        x = self.features(x)
        x = self.flatten(x)
        logits = self.classifier(x)
        return logits

model = SmallCNN(num_classes=10)
images = torch.randn(16, 3, 32, 32)
logits = model(images)

print("logits shape:", logits.shape)
assert logits.shape == (images.size(0), 10)
```

```python
import torch
import torch.nn as nn

class ImageMLP(nn.Module):
    """
    CIFAR-10 이미지를 flatten한 뒤 분류하는 MLP baseline입니다.
    입력: (N, 3, 32, 32)
    출력: (N, 10)
    """
    def __init__(self, hidden_dim=256, num_classes=10):
        super().__init__()

        self.model = nn.Sequential(
            # 이미지를 한 줄로 펼칩니다.
            nn.Flatten(),

            # 3*32*32 = 3072개의 입력 feature를 hidden_dim으로 변환합니다.
            nn.Linear(3 * 32 * 32, hidden_dim),
            nn.ReLU(),

            # hidden feature를 class별 logits로 변환합니다.
            nn.Linear(hidden_dim, num_classes)
        )

    def forward(self, x):
        logits = self.model(x)
        return logits
```

```python
# RNNClassifier 예제
import torch
import torch.nn as nn
class RNNClassifier(nn.Module):
    def __init__(self, input_size, hidden_size, num_classes):
        super().__init__()
        self.rnn = nn.RNN(
            input_size=input_size,
            hidden_size=hidden_size,
            batch_first=True
        )
        self.fc = nn.Linear(hidden_size, num_classes)
    def forward(self, x, lengths=None):
        output, h_n = self.rnn(x)
        if lengths is None:
            # 고정 길이·무패딩인 경우입니다.
            last_hidden = output[:, -1, :]
        else:
            if lengths.dtype not in (
                torch.uint8, torch.int8, torch.int16, torch.int32, torch.int64
            ):
                raise TypeError("lengths는 정수 dtype이어야 합니다.")
            if lengths.ndim != 1 or lengths.size(0) != x.size(0):
                raise ValueError("lengths shape는 (batch,)여야 합니다.")
            lengths = lengths.to(x.device, dtype=torch.long)
            if torch.any(lengths < 1) or torch.any(lengths > x.size(1)):
                raise ValueError("각 length는 1 이상 seq_len 이하여야 합니다.")
            batch_index = torch.arange(x.size(0), device=x.device)
            last_index = lengths - 1
            last_hidden = output[batch_index, last_index]
        return self.fc(last_hidden)
# 고정 길이·무패딩 예시
x = torch.randn(4, 6, 3)
model = RNNClassifier(input_size=3, hidden_size=8, num_classes=3)
logits = model(x)
print(logits.shape)  # torch.Size([4, 3])
# 오른쪽 padding 예시
padded_x = torch.randn(3, 6, 3)
lengths = torch.tensor([6, 4, 2])
padded_x[1, 4:] = 0.0
padded_x[2, 2:] = 0.0
logits = model(padded_x, lengths=lengths)
print(logits.shape)  # torch.Size([3, 3])
```

```python
# LSTMClassifier
import torch
import torch.nn as nn

class LSTMClassifier(nn.Module):
    def __init__(self, input_size, hidden_size, num_classes):
        super().__init__()
        self.lstm = nn.LSTM(
            input_size=input_size,
            hidden_size=hidden_size,
            batch_first=True
        )
        self.fc = nn.Linear(hidden_size, num_classes)

    def forward(self, x, lengths=None):
        output, (h_n, c_n) = self.lstm(x)

        if lengths is None:
            last_hidden = output[:, -1, :]
        else:
            if lengths.dtype not in (
                torch.uint8, torch.int8, torch.int16, torch.int32, torch.int64
            ):
                raise TypeError("lengths는 정수 dtype이어야 합니다.")
            if lengths.ndim != 1 or lengths.size(0) != x.size(0):
                raise ValueError("lengths shape는 (batch,)여야 합니다.")

            lengths = lengths.to(x.device, dtype=torch.long)
            if torch.any(lengths < 1) or torch.any(lengths > x.size(1)):
                raise ValueError("각 length는 1 이상 seq_len 이하여야 합니다.")
            batch_index = torch.arange(x.size(0), device=x.device)
            last_index = lengths - 1
            last_hidden = output[batch_index, last_index]

        return self.fc(last_hidden)


x = torch.randn(4, 6, 3)
model = LSTMClassifier(input_size=3, hidden_size=8, num_classes=2)
logits = model(x)
print(logits.shape)  # torch.Size([4, 2])
```
