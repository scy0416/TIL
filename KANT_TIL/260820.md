- 딥러닝 기초2-3
  - 텐서를 만들 때에는 텐서가 저장되어 있는 장소를 잘 고려해야한다.
  - CPU와 GPU(CUDA)에 존재할 수 있으며, 기본적으로는 CPU에 위치한다.
  - 만약 GPU에 이동시키고 싶다면 `x.to("CUDA")`와 같이 옮길 수 있다.
  - 연산을 하기 위해서는 연산에 참여하는 대상자들이 전부 같은 공간에 있어야 한다.
  - 입력, 모델, 레이블 전부 똑같이 CPU나 GPU에 있어야 한다.
  - 서로 다른 공간에 있는데 연산을 시도하고자 한다면 오류가 발생한다.
  - 또한 `.device()`를 통해서 특정 모델 또는 텐서가 위치만 디바이스를 알아낼 수 있다.
  - 그리고 그 디바이스를 이용해서 `.to(device)`도 가능하다.
- 딥러닝 기초2-4
  - `nn.Linear`를 사용할 때에는 입력 차원 오류를 신경써야 한다.
  - 입력 텐서의 마지막 차원(특성)의 크기가 `in_features`와 같아야 하는 것이다.
  - 입력된 데이터는 출력차원인 `out_features`로 바뀌게 된다.
  - 입력 텐서와 `in_features`가 다르면 오류가 발생한다.
  - 이를 해결하기 위해서 Linear의 `in_features`의 크기를 바꾸거나 입력 텐서의 마지막 차원의 크기를 바꾼다.
  - batch차원이 누락되더라도 동작 자체는 하며, 명확하게 하기 위해서 unsqueeze는 하는게 좋다.
  - `nn.CrossEntropyLoss`를 사용할 때에는 dtype을 신경써야 한다.
  - 크로스 엔트로피는 다중 클래스에 대해서 처리하기 때문에 `torch.long`이어야 한다.
- 딥러닝 기초3-1
  - 퍼셉트론은 기본적으로 `z = x1*w1 + x2*w2 + x3*w3 + ... xn*wn + b`의 형태이다.
  - 퍼셉트론은 입력 특성들에 대해서 서로 다른 집중도를 가지며 이것을 가중치라고 한다.
  - 가중치와 편향이 있기 때문에 퍼셉트론은 선형 결정 경계를 만들어낼 수 있다.
- 딥러닝 기초3-2
  - MLP는 Multi-layer Perceptron으로 퍼셉트론을 여러 겹 쌓은 것이다.
  - 기본적인 퍼셈트론에 은닉층이 더해졌다.
  - 은닉층은 입력된 데이터를 새로운 표현으로 변환하는 역할을 한다.
  - Linear(3, 5), ReLU(), Linear(5, 3)에 해당하는 MLP가 있다면 입력 값은 (n, 3)이고, 은닉층으로는 5개의 feature가 보내진다.
  - ReLU는 shape를 변경하지 않기 때문에 은닉층은 5개의 feature을 그대로 받는다.
  - 출력은 5에서 3으로 줄어들게 된다.
  - 이 때에 Linear(n, m)의 값이 shape가 (n, m)이 아니라 (입력 feature의 크기, 출력 feature의 크기) 임을 고려해야 한다.
  - MLP에서 depth는 MLP의 전체 층의 깊이이고, width는 각 은닉층의 뉴런의 개수이다.
  - hidden size는 은닉층의 출력 feature수이다.
  - 입력 차원과 은닉 차원, 출력 차원을 알면 전체 파라미터의 수를 알아낼 수 있다.
  - input_dim = 3, hidden_dim = 5, num_classes = 2일 때, 첫 층의 weight의 수 = 3 * 5 = 15, 첫 층의 bias의 수 = 5, 둘째 층의 weight의 수 = 5 * 2 = 10, 둘째 층의 bias의 수 = 2로 전체 파라미터는 32개가 된다.
  - hidden_size를 바꾸면 전체 파라미터의 수가 변하게 된다.
- 딥러닝 기초3-3
  - `nn.Linear`에는 weight, bias가 들어있다.
  - 그렇기 때문에 `nn.Linear(n, m).weight`와 `nn.Linear(n, m).bias`가 존재하는데, 이 때 bias의 shape는 m이지만, weight의 shape는 특이하게 (n, m)이 아니라 (m, n)이 있다.
  - 이건 튜터님도 왜그런지 모르겠다고 하니까 그냥 외워야겠다.
  - `named_parameters()`를 사용하면 각 층의 파라미터를 자세하게 확인할 수 있다.
- 딥러닝 기초3-4
  - MLP는 기본적으로 (batch_size, features)를 입력으로 받았다.
  - 하지만 텐서의 종류에는 2차원을 넘는 3~4차원도 존재한다.
  - 이미지가 대표적으로 그러며, 이를 그냥 넣을 수는 없고, 하나의 긴 features로 늘러야 한다.
  - 이 과정을 flatten이라고 한다.
  - 만약 이미지 배치 데이터(16, 1, 28, 28)을 입력하고자 한다면 flatten을 통해서 (16, 784)사이즈로 맞추고 입력을 해야한다.
  - 이를 위해서 함수 `torch.flatten(start_dim=1)`을 사용할 수 있다. start_dim=1은 flatten을 시작할 차원을 말하는 것으로, 없다면 batch까지 flatten한다.
  - `nn.Sequential`에서 사용하기 위해서는 `nn.Flatten()`을 사용할 수 있다.
  - 여기서는 start_dim을 명시할 필요가 없는데, 기본적으로 batch가 있을 것으로 기대되는 입력이기 때문에 가장 왼쪽 차원은 자동으로 batch로 인식하고 나머지를 flatten 한다.
  - flatten의 다른 형태로는 `view`, `reshape`가 있다.
- 딥러닝 기초3-5
  - MLP는 `nn.Sequential`으로만 구성해야하는 것은 아니며, 커스텀하게 `nn.Module`을 상속한 클래스를 MLP로써 만들 수 있다.
  - 유의사항으로 `__init__`에서 `super().__init__()`을 호출해서 초기화를 진행해줘야 한다.
  - 또한 `__init__`에서 각 레이어를 구성하고 `forward()`에서 계산 흐름을 만들어줘야 한다.
  - 그리고 만들어진 모델은 `.forward()`를 호출할 필요 없이 `model(x)`와 같은 형태로 계산할 수 있다.
  - 이건 매직 메소드 `__call__`을 통해서 구현된 것을 소스 코드로 확인하였다.

```python
# 기본적인 퍼셉트론을 직접 계산하는 예제
import torch

# 입력 feature 2개를 가진 샘플 하나입니다.
# 예를 들어 x[0]은 공부 시간, x[1]은 모의고사 점수라고 생각할 수 있습니다.
x = torch.tensor([2.0, 3.0])

# 각 feature에 곱할 가중치입니다.
# w[0]은 첫 번째 feature의 중요도,
# w[1]은 두 번째 feature의 중요도입니다.
w = torch.tensor([1.5, -0.5])

# 편향은 전체 점수를 한 번 더 이동시키는 값입니다.
b = torch.tensor(-1.0)

# 퍼셉트론의 가중합을 계산합니다.
# z = x1*w1 + x2*w2 + b
z = (x * w).sum() + b

# 점수가 0 이상이면 class 1, 아니면 class 0으로 예측합니다.
pred = 1 if z >= 0 else 0

print("weighted sum z:", z.item())
print("prediction    :", pred)
```
```python
# nn.Sequential을 통해서 만든 2층짜리 MLP 예제
import torch
import torch.nn as nn

# 재현 가능한 예시를 위해 seed를 고정합니다.
torch.manual_seed(42)

# 샘플 4개, feature 3개인 입력입니다.
X = torch.randn(4, 3)

# MLP 구조를 정의합니다.
# Linear(3, 5): 입력 feature 3개를 hidden feature 5개로 변환합니다.
# ReLU(): 은닉층 결과에 비선형성을 추가합니다. 자세한 내용은 4장에서 다룹니다.
# Linear(5, 2): hidden feature 5개를 class 2개에 대한 점수로 변환합니다.
model = nn.Sequential(
    nn.Linear(3, 5),
    nn.ReLU(),
    nn.Linear(5, 2)
)

# 모델에 입력을 넣으면 출력 logits가 나옵니다.
logits = model(X)

print("X shape     :", X.shape)
print("logits shape:", logits.shape)
print(logits)
```

```python
# nn.Module을 상속하는 커스텀 모델을 만드는 예제
import torch
import torch.nn as nn

class SimpleMLP(nn.Module):
    """
    28x28 흑백 이미지를 입력으로 받아
    class별 logits를 출력하는 간단한 MLP 모델입니다.
    """

    def __init__(self, input_dim=1 * 28 * 28, hidden_dim=128, num_classes=10):
        """
        모델에 필요한 layer를 정의합니다.

        input_dim:
            flatten 이후 샘플 하나가 가지는 feature 수입니다.
            1x28x28 이미지는 784개 feature를 가집니다.

        hidden_dim:
            은닉층의 출력 feature 수입니다.
            이 값이 커질수록 모델 parameter 수가 늘어납니다.

        num_classes:
            분류할 class 수입니다.
            출력 logits의 마지막 차원이 됩니다.
        """
        super().__init__()

        # 이미지 입력을 (batch_size, features) 형태로 펼칩니다.
        self.flatten = nn.Flatten()

        # 첫 번째 선형층입니다.
        # input_dim개의 feature를 hidden_dim개의 feature로 변환합니다.
        self.fc1 = nn.Linear(input_dim, hidden_dim)

        # 은닉층 뒤에 사용할 활성화 함수입니다.
        # 자세한 활성화 함수 내용은 4장에서 다룹니다.
        self.relu = nn.ReLU()

        # 마지막 출력층입니다.
        # hidden_dim개의 feature를 num_classes개의 logits로 변환합니다.
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        """
        입력 Tensor x가 모델을 통과하는 순서를 정의합니다.
        """
        # x shape: (batch_size, 1, 28, 28)
        x = self.flatten(x)

        # x shape: (batch_size, 784)
        x = self.fc1(x)

        # x shape: (batch_size, hidden_dim)
        x = self.relu(x)

        # logits shape: (batch_size, num_classes)
        logits = self.fc2(x)

        return logits
```
