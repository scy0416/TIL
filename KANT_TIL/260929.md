  - 호출이 한 두번 정도로 적으면 굳이 랭체인 쓸거 없이 직접 SDK를 호출하는게 좋다
  - 프롬프트와 출력 형식을 자주 바꾸거나 재사용할 때에는 랭체인이 좋다
- LangChain1-2
  - `pyproject.toml`에는 직접 사용하는 패키지와 파이썬 조건이, `uv.lock`에는 간접 의존성가지 해석된 버전이 기록된다.
  - 두 파일과 `.python-version`이 함께 있으면 프로젝트를 수월하게 관리할 수 있다.
  - 직접 새 프로젝트를 만드는 경우에는 `pyproject.toml`이 없기 때문에 다음 명령어를 사용한다.

```commandline
uv init --bare --python 3.12
uv python pin 3.12
uv add "langchain==1.3.14" "langchain-core==1.5.1" "langchain-openai==1.4.1" "openai==2.48.0" "python-dotenv==1.2.2" "pydantic==2.13.5"
```
  - 패키지들의 의존성 충돌을 확인하기 위해서 `uv pip check`를 사용하면 된다.
- LangChain2-1
  - `PromptTamplate`의 `format`은 프롬프트 템플릿을 통해서 단순 문자열을 만들기 위해서 사용한다.
  - `invoke`는 비슷하게 사용하지만 runnable을 통해서 LCEL을 구성하는데, `StringPromptValue`를 반환하여 곧바로 다음 runnable의 입력이 될 수 있다.
  - `input_variables`를 통해서 프롬프트 템플릿이 기대하는 변수들을 확인할 수 있다.
  - `ChatPromptTemplate`는 각 메시지의 역할을 구분하면서 사용할 수 있는 프롬프트 템플릿으로, `from_messages`를 사용해서 초기화할 수 있지만 곧바로 생성자를 호출하는 것도 가능하다.
  - 또한 튜플 형식이 아니라 역할 메시지 객체를 직접 입력하는 것도 가능하다.
- LangChain2-2
  - 단계별 자료형

| 단계                 | 받는 값            | 내보내는 값        |
|----------------------|--------------------|--------------------|
| `ChatPromptTemplate` | 입력 변수의 값     | 역할별 메시지 목록 |
| `ChatOpenAI`         | 역할별 메시지 목록 | `AIMessage`        |
| `StrOutputParser`    | `AIMessage`        | `str`              |
| List Parser          | `AIMessage`        | `list[str]`        |
| JSON Parser          | `AIMessage`         | `dict` 또는 `list`  |
  - `StrOutputParser`의 역할은 `AIMessage`의 속성들 중에서 실제 답변에 속하는 `content`만을 보내고 나머지를 버리는 것이다.
  - 역할 자체가 `AIMessage`의 파싱이기 때문에 굳이 모델의 출력이 아니더라도 `AIMessage`면 동작한다.
  - 물론 주로 `AIMessage`의 파싱에 쓰이는 것이지 `BaseMessage`를 상속하는 모든 메시지에서 사용 가능하다.
  - `CommaSeparatedListOutputParser`는 쉼표로 구분된 메시지를 `list[str]`의 형식으로 파싱해주는 파서이다.
  - `get_format_instructions()`를 통해서 파서가 기대하는 출력 형식에 대한 정보를 받을 수 있다.
  - `JsonOutputParser`는 `CommaSeparatedListOutputParser`와 다르게 JSON형식으로 파싱을 하는 파서이다.
  - JSON형식으로 출력을 하기에 구조화 출력인가 생각할 수 있지만 구조화 출력이랑은 동작 방식이 다르기 때문에 안정성은 좀 떨어진다.

## 왜 중요한가
- LangChain에 대한 기본적인 내용이기 때문에 알고 넘어가는 편이 좋다.
- 이후에 나올 LCEL같은 경우는 이런 기초적인 내용이 뒷받쳐주지 않으면 할 수 없기 때문에 필수다.

## 느낀점
- 이미 공부한 적 있는 LangChain이라 그런가 크게 어렵다는 느낌은 없다.
- 단지 이후에 나올 LCEL파트에서 얼마나 어려워질지 기대가 되는 것은 있다.

## 코드/예시
```python
# 프롬프트 단계 예제
# 역할별 메시지를 만들 수 있는 ChatPromptTemplate을 가져옵니다.
from langchain_core.prompts import ChatPromptTemplate

# system 메시지는 고정하고, human 메시지의 질문만 실행할 때 바뀌게 만듭니다.
prompt = ChatPromptTemplate.from_messages(
    [
        ("system", "당신은 어려운 AI 용어를 쉽게 설명하는 튜터입니다."),
        ("human", "{question}"),
    ]
)

# question 변수에 실제 질문을 넣어 역할별 메시지 목록을 만듭니다.
messages = prompt.format_messages(
    question="프롬프트가 무엇인지 두 문장으로 설명해 주세요."
)
```
```python
# 모델 단계 예제
# .env에서 지정한 권장 모델을 읽습니다.
import os
from dotenv import load_dotenv

# OpenAI 모델을 LangChain 방식으로 연결하는 클래스를 가져옵니다.
from langchain_openai import ChatOpenAI

# 사용할 모델을 지정해 ChatModel 객체를 만듭니다.
load_dotenv()

model = ChatOpenAI(model=os.getenv("OPENAI_MODEL", "gpt-5.6-luna"))

# Prompt가 만든 메시지를 모델에 전달해 AIMessage 응답을 받습니다.
ai_message = model.invoke(messages)
```
```python
# 파서 단계 예제
# AIMessage의 본문을 문자열로 바꾸는 Parser를 가져옵니다.
from langchain_core.output_parsers import StrOutputParser

# 문자열 변환을 담당할 Parser 객체를 만듭니다.
parser = StrOutputParser()

# AIMessage를 Parser에 전달해 최종 문자열을 얻습니다.
answer = parser.invoke(ai_message)

# 화면에 표시할 문자열을 출력합니다.
print(answer)
```
```python
# PromptTemplate 예제
# 일반 문자열 Prompt를 만드는 PromptTemplate을 가져옵니다.
from langchain_core.prompts import PromptTemplate

# topic과 audience가 실행할 때 바뀌는 입력 변수입니다.
template = PromptTemplate.from_template(
    "주제:{topic}\n"
    "독자 수준:{audience}\n"
    "주제를 한 문장으로 설명하세요."
)

# 두 입력 변수에 실제 값을 넣어 완성된 문자열을 만듭니다.
formatted_prompt = template.format(
    topic="LangChain",
    audience="파이썬 입문자",
)

# 변수 치환이 끝난 문자열을 출력합니다.
print(formatted_prompt)
```
```python
# StrOutputParser 사용 예제
# AIMessage의 본문을 문자열로 바꾸는 Parser를 가져옵니다.
from langchain_core.output_parsers import StrOutputParser

# 문자열 변환을 담당할 Parser 객체를 만듭니다.
parser = StrOutputParser()

# 모델이 반환한 AIMessage를 Parser에 전달합니다.
text_result = parser.invoke(ai_message)

# 변환된 값과 문자열 여부를 함께 확인합니다.
print(text_result)
print(isinstance(text_result, str))
```
```python
# CommaSeparatedListOutputParser 사용 예제
# 쉼표 구분 문자열을 리스트로 바꾸는 Parser를 가져옵니다.
from langchain_core.output_parsers import CommaSeparatedListOutputParser

# List Parser 객체를 만듭니다.
list_parser = CommaSeparatedListOutputParser()

# 모델에게 어떤 형식으로 답해야 하는지 알려 줄 문장을 확인합니다.
format_instructions = list_parser.get_format_instructions()

# Prompt에 넣을 형식 안내를 출력합니다.
print(format_instructions)

# 형식 안내와 사용자 질문이 들어갈 역할 기반 Prompt를 만듭니다.
list_prompt = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            "질문에 맞는 핵심 키워드만 반환하세요.\n"
            "출력 형식:{format_instructions}",
        ),
        ("human", "{question}"),
    ]
)

# Parser의 형식 안내와 실제 질문을 Prompt에 전달합니다.
list_messages = list_prompt.format_messages(
    format_instructions=list_parser.get_format_instructions(),
    question="LangChain 기본 체인의 구성 요소 세 개를 알려 주세요.",
)

# 모델이 쉼표로 구분된 답변을 생성하도록 메시지를 전달합니다.
list_ai_message = model.invoke(list_messages)

# 모델 응답을 Python 리스트로 변환합니다.
list_result = list_parser.invoke(list_ai_message)

# 변환된 리스트와 자료형을 확인합니다.
print(list_result)
print(type(list_result).__name__)
```
```python
# JsonOutputParser 사용 예제
# JSON 문자열을 Python 값으로 바꾸는 Parser를 가져옵니다.
from langchain_core.output_parsers import JsonOutputParser

# JSON Parser 객체를 만듭니다.
json_parser = JsonOutputParser()

# 필요한 키와 출력 형식 안내가 들어간 Prompt를 만듭니다.
json_prompt = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            "질문을 분류하고 category와 reason 키를 가진 JSON 객체로 답하세요.\n"
            "출력 형식:{format_instructions}",
        ),
        ("human", "{question}"),
    ]
)

# 형식 안내와 분류할 질문을 메시지에 넣습니다.
json_messages = json_prompt.format_messages(
    format_instructions=json_parser.get_format_instructions(),
    question="PromptTemplate은 어떤 역할을 하나요?",
)

# 모델에 JSON 형식의 답변을 요청합니다.
json_ai_message = model.invoke(json_messages)

# 모델 응답을 Python 값으로 변환합니다.
json_result = json_parser.invoke(json_ai_message)

# 이번 Prompt는 JSON 객체를 요구했으므로 dict인지 확인합니다.
if not isinstance(json_result, dict):
    raise TypeError("JSON 객체를 기대했지만 다른 자료형이 반환되었습니다.")

# category와 reason 키가 모두 있는지 확인합니다.
if "category" not in json_result or "reason" not in json_result:
    raise ValueError("JSON 결과에 category 또는 reason 키가 없습니다.")

# 후속 코드가 사용할 category 값을 키로 읽습니다.
print(json_result["category"])

# 전체 결과의 Python 자료형을 확인합니다.
print(type(json_result).__name__)
```
