## 오늘 배운 것
- 딥러닝 심화3-1
  - 토큰화된 시퀀스는 토큰들이 서로를 참고해야 문맥을 알아낼 수 있다.
  - 토큰은 기본적으로 자기 자신에 대한 정보가 있고, 시퀀스 내의 다른 토큰들과의 관계가 합쳐져서 시퀀스 내의 문맥 정보가 포함된 정보가 된다.
  - 어텐션은 현재 현재 토큰이 시퀀스 내의 다른 토큰들과의 관계를 보고서 선택적으로 정보를 취합하는 방식이다.
  - 어텐션을 계산할 때에는 Q, K, V를 계산해서 구한다.
    - Q: 찾고자 하는 정보
    - K: Q에 대한 연관도
    - V: 토큰이 가지는 실제 정보
  - 각 토큰에 대한 어텐션은 Q@K^T를 통해서 구할 수 있다.
  - 이렇게 나온 스코어는 각 토큰에 대해서 얼마나 참조할지에 대한 가중치이며, 이 값을 소프트맥스하면 최종 스코어가 된다.
  - 그렇게 구해진 스코어와 V를 곱하면 토큰의 시퀀스에 대한 문맥 정보가 되는 것이다.
  - Q, K, V는 입력에 대해서 W_q, W_k, W_v를 projection한 선형 변환의 결과이다.
- 딥러닝 심화3-2
  - Scaled Dot-Product Attention 계산 공식은 다음과 같다.
  - `Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V`
  - 단계별로 본다면 다음과 같다.
    - 비교: `QKᵀ`
    - 조절: `QKᵀ / √dₖ`
    - 비율: `softmax(QKᵀ / √dₖ)`
    - 섞기: `softmax(QKᵀ / √dₖ) V`
  - score matrix는 모든 q와 k에 대한 v를 표의 형식으로 만든 것이다.
  - score matrix를 통해서 q와 k에 대한 v를 바로 확인할 수 있다.
  - 크기는 L*L이다.
  - 스케일링은 특정 토큰에 과한 집중이 일어날 때, 이를 완화해주기 위해서 진행한다.
  - 소프트맥스는 score를 유효한 가중치의 영역으로 만들기 위해서 사용한다.
  - 스코어는 음수일 수도 있기 때문에 소프트맥스로 모든 값을 양수 범위로 만들어서 처리될 수 있도록 만든다.
  - 어텐션의 shape 흐름

| 단계 | Tensor      | Shape     | 의미                     |
|------|-------------|-----------|--------------------------|
| 입력 | Q           | [B, L, D] | 각 토큰의 질문 표현      |
| 입력 | K           | [B, L, D] | 각 토큰의 비교 기준 표현 |
| 입력 | V           | [B, L, D] | 각 토큰에서 가져올 정보  |
| 비교 | Q@K^T       | [B, L, L] | 토큰x토큰 관련도 표      |
| 비율 | Softmax     | [B, L, L] | 토큰x토큰 참고 비율      |
| 혼합 | weights @ v | [B, L, D] | 문맥에 반영된 토큰 표현  |
- 딥러닝 심화3-3
  - 어텐션 스코어를 소프트맥스하여 만들어진 attention weight는 다른 k를 얼마나 참고할지에 대한 정보이다.
  - Attention Heatmap은 각 Q와 K에 대한 V인 attention weight를 표 형식으로 만들어둔 것이다.
  - 행은 토큰들의 Q, 열은 참고 대상 토큰들의 K이다.
  - 맞물리는 값이 qk에 대한 weight 값이다.
  - Attention weight를 통해서 각 토큰들의 V값을 곱하고 더한 결과는 새로운 문맥에 대한 정보이고 이를 Context Vector라고 한다.
  - 같은 토큰이어도 시퀀스 내의 문맥에 따라서 서로 다른 의미로 인식되는 것이 가능하다.
  - Attention weight는 어떤 위치를 얼마나 참고하는지에 대한 정보이지 얼마나 중요한지에 대한 직관적인 정보로 생각하는건 좋지 않다.
- 딥러닝 심화3-4
  - 어텐션 계산에 있어서 마스크를 적용할 수 있는데, 이는 유효하지 않은 토큰(예: 특수 토큰 `[CLS]`, `[SEP]`등)의 계산을 방지하는데에 사용된다.
  - 찾아보니 미래의 정보를 보지 못하도록 하는 마스킹도 마스킹의 한 종류였다.
  - 어텐션 계산을 위한 PyTorch API는 `torch.nn.functional.scaled_dot_product_attention()`이다.
- 딥러닝 심화3-5
  - 멀티 헤드 어텐션이란 헤드마다 서로 다른 관점에서 관계를 파악하는 것이다.
  - 그렇다고 해서 각 헤드마다 역할이 미리 주어져서 학습되는건 아니다.
  - Multi-Head Attention에서 전체 표현 차원(임베딩 공간)을 `H`개로 나눈다.
  - 이 때 정확히 나누어 떨어져야 한다.
  - 각 헤드의 QKV는 같지 않고 다른 값을 가진다.
  - 그렇다고 해서 학습할 파라미터는 늘어나지 않는데, 이 QKV자체를 나눠서 학습할 뿐이지 총량은 같기 때문이다.
  - 이는 각 헤드마다 정해진 정보 공간에서 서로 다른 관점에서 토큰들의 관계를 분석한다고 보면 된다.
  - 구현 흐름은 입력 X [B, L, D_model]에 대해서 다음과 같다.
    - Q, K, V 선형 투영 [B, L, D_model]
    - Head 분리 [B, H, L, D_head]
    - Head별 Attention 계산
    - Head 결과 [B, H, L, D_head]
    - Head 결합 [B, L, D_model]
    - Output Projection W_O
    - 최종 출력 [B, L, D_model]
  - 헤드마다의 결과를 단순히 이어붙이는 것으로는 나열에 불과하기 때문에 W_O를 통해서 결과를 섞어서 다음 레이어가 사용가능한 형태로 만든다.
  - PyTorch의 MHA에서의 입출력 shape는 다음과 같다.
    - Query 입력: `[B, L_query, D_model]`
    - Key 입력: `[B, L_key, D_model]`
    - Value 입력: `[B, L_key, D_model]`
    - Output: `[B, L_query, D_model]`
    - Head별 weight: `[B, H, L_query, L_key]`

## 왜 중요한가
- LLM의 핵심이라고 할 수 있는 부분이기 때문에 굉장히 중요하다.
- 사실상 LLM이 문맥을 어떻게 유지하고 문맥을 어떻게 인식하는지에 대한 내용이기 때문에 이걸 안다면 LLM을 만들 수 있을지도 모른다.

```python
# Q, K, V shape 확인 예제
import torch
from torch import nn

# 예시 입력의 크기를 정합니다.
# B=2: 문장 두 개를 한 번에 처리합니다.
# L=5: 각 문장을 토큰 길이 5로 맞췄다고 가정합니다.
# D=8: 각 토큰을 8개의 숫자로 표현한다고 가정합니다.
B, L, D = 2, 5, 8

# x는 토큰의 현재 표현입니다.
# shape은 [배치, 토큰 길이, 표현 차원] = [B, L, D]입니다.
x = torch.randn(B, L, D)

# Q, K, V를 만들기 위한 서로 다른 선형 계층입니다.
# 세 계층 모두 입력과 출력 차원은 D로 같지만, 학습되는 가중치는 서로 다릅니다.
to_q = nn.Linear(D, D, bias=False)
to_k = nn.Linear(D, D, bias=False)
to_v = nn.Linear(D, D, bias=False)

# 같은 x에서 출발하지만 서로 다른 선형 계층을 통과합니다.
q = to_q(x)
k = to_k(x)
v = to_v(x)

# 선형 계층은 마지막 차원 D만 변환하므로 B와 L은 유지됩니다.
print("x shape:", x.shape)
print("q shape:", q.shape)
print("k shape:", k.shape)
print("v shape:", v.shape)

# Q, K, V는 모두 [B, L, D] shape인지 확인합니다.
assert q.shape == (B, L, D)
assert k.shape == (B, L, D)
assert v.shape == (B, L, D)
```
```python
# 어텐션 스코어 계산 예제
import math
import torch

# 결과를 다시 실행해도 동일하게 만들기 위해 seed를 고정합니다.
torch.manual_seed(42)

# 토큰 세 개를 각각 2차원 벡터로 표현한 아주 작은 예제입니다.
# B=1: 문장 한 개
# L=3: 토큰 세 개
# D=2: 각 토큰 표현 차원 두 개
q = torch.tensor(
    [[[1.0, 0.0],
      [0.0, 1.0],
      [1.0, 1.0]]],
    dtype=torch.float32,
)

# 이해를 단순하게 하기 위해 K도 같은 값을 사용합니다.
# 실제 Transformer에서는 Q와 K가 서로 다른 projection을 통과합니다.
k = q.clone()

# Value는 가져올 실제 정보입니다.
# 여기서는 계산 결과를 읽기 쉽도록 간단한 값을 사용합니다.
v = torch.tensor(
    [[[1.0, 0.0],
      [0.0, 1.0],
      [1.0, 1.0]]],
    dtype=torch.float32,
)

# K의 마지막 두 축을 바꿉니다.
# K:   [B, L, D] = [1, 3, 2]
# K^T: [B, D, L] = [1, 2, 3]
k_t = k.transpose(-2, -1)

# 모든 Query와 모든 Key의 dot-product score를 한 번에 계산합니다.
# [1, 3, 2] @ [1, 2, 3] -> [1, 3, 3]
scores = torch.matmul(q, k_t)

# d_k는 Query/Key의 마지막 차원입니다.
d_k = q.size(-1)

# score의 크기를 조절합니다. Shape은 바뀌지 않습니다.
scaled_scores = scores / math.sqrt(d_k)

# 각 Query 행에서 모든 Key에 대한 참고 비율을 만듭니다.
# 마지막 축이 Key 축이므로 dim=-1을 사용합니다.
weights = torch.softmax(scaled_scores, dim=-1)

# Attention weight만큼 Value를 섞습니다.
# [1, 3, 3] @ [1, 3, 2] -> [1, 3, 2]
context = torch.matmul(weights, v)

print("scores shape:", scores.shape)
print("weights shape:", weights.shape)
print("context shape:", context.shape)

# 소수 셋째 자리까지 반올림해 출력합니다.
print("scores:\n", scores.round(decimals=3))
print("weights:\n", weights.round(decimals=3))
print("context:\n", context.round(decimals=3))

# 각 Query의 weight 합이 1인지 확인합니다.
print("weight row sums:", weights.sum(dim=-1))

assert scores.shape == (1, 3, 3)
assert weights.shape == (1, 3, 3)
assert context.shape == (1, 3, 2)
assert torch.allclose(
    weights.sum(dim=-1),
    torch.ones(1, 3),
    atol=1e-6,
)
```

```python
# context vector 계산 예제
import torch

# 한 Query가 네 개 Key에 준 Attention weight입니다.
# Shape [B=1, L_query=1, L_key=4]입니다.
weights = torch.tensor(
    [[[0.25, 0.15, 0.45, 0.15]]],
    dtype=torch.float32,
)

# 네 개 토큰 위치의 Value입니다.
# 각 Value는 2차원 벡터라고 가정합니다.
# Shape [B=1, L_key=4, D_value=2]입니다.
values = torch.tensor(
    [[[1.0, 0.0],   # 민수 관련 정보
      [0.0, 1.0],   # 식당 관련 정보
      [1.0, 1.0],   # 라면 관련 정보
      [0.5, 0.5]]], # 행동 관련 정보
    dtype=torch.float32,
)

# Attention weight와 Value를 행렬곱합니다.
# [1,1,4] @ [1,4,2] -> [1,1,2]
context = torch.matmul(weights, values)

print("weights shape:", weights.shape)
print("values shape:", values.shape)
print("context shape:", context.shape)
print("context:", context)

# Weight 한 행의 합이 1인지 확인합니다.
assert torch.allclose(
    weights.sum(dim=-1),
    torch.ones(1, 1),
    atol=1e-6,
)

# 출력은 Query 하나에 대한 2차원 새 표현입니다.
```

```python
# MHA 처리 예제
import math

import torch
from torch import nn

BATCH_SIZE = 2
SEQUENCE_LENGTH = 5
D_MODEL = 8
NUM_HEADS = 2

assert D_MODEL % NUM_HEADS == 0
D_HEAD = D_MODEL // NUM_HEADS

# Transformer Block에 들어오는 토큰 표현입니다.
# Shape: [B, L, D_model]
x = torch.randn(BATCH_SIZE, SEQUENCE_LENGTH, D_MODEL)

# 서로 다른 학습 가능한 선형변환으로 Q, K, V를 만듭니다.
q_proj = nn.Linear(D_MODEL, D_MODEL, bias=False)
k_proj = nn.Linear(D_MODEL, D_MODEL, bias=False)
v_proj = nn.Linear(D_MODEL, D_MODEL, bias=False)
out_proj = nn.Linear(D_MODEL, D_MODEL, bias=False)

q = q_proj(x)
k = k_proj(x)
v = v_proj(x)

# [B, L, D_model] -> [B, L, H, D_head] -> [B, H, L, D_head]
q_heads = q.reshape(BATCH_SIZE, SEQUENCE_LENGTH, NUM_HEADS, D_HEAD).transpose(1, 2)
k_heads = k.reshape(BATCH_SIZE, SEQUENCE_LENGTH, NUM_HEADS, D_HEAD).transpose(1, 2)
v_heads = v.reshape(BATCH_SIZE, SEQUENCE_LENGTH, NUM_HEADS, D_HEAD).transpose(1, 2)

# 모든 Query-Key 조합의 점수를 계산합니다.
# [B,H,L,D_head] @ [B,H,D_head,L] -> [B,H,L,L]
scores = torch.matmul(q_heads, k_heads.transpose(-2, -1)) / math.sqrt(D_HEAD)
weights = torch.softmax(scores, dim=-1)

# Head별로 Value를 섞습니다.
# [B,H,L,L] @ [B,H,L,D_head] -> [B,H,L,D_head]
head_context = torch.matmul(weights, v_heads)

# [B,H,L,D_head] -> [B,L,H,D_head] -> [B,L,D_model]
merged_context = (
    head_context.transpose(1, 2)
    .contiguous()
    .reshape(BATCH_SIZE, SEQUENCE_LENGTH, D_MODEL)
)

# 여러 head의 정보를 다시 섞는 Output Projection입니다.
output = out_proj(merged_context)

assert q_heads.shape == (BATCH_SIZE, NUM_HEADS, SEQUENCE_LENGTH, D_HEAD)
assert weights.shape == (BATCH_SIZE, NUM_HEADS, SEQUENCE_LENGTH, SEQUENCE_LENGTH)
assert output.shape == x.shape

print("Q head shape:", q_heads.shape)
print("Attention weight shape:", weights.shape)
print("MHA output shape:", output.shape)
```

## 헷갈렸던 부분 & 해결
- 일단 레이어에서 기억에 대한 정보가 어떻게 전달되는지에 대해서 잘못 생각하고 있었다.
- 기억이 이어져간다고 생각했지만 실제로는 그런게 아니라 시퀀스 내의 이전 토큰에 직접 연관성을 계산하는 방식이었다.
- 분명 RNN/LSTM에서 그 이유 때문에 나왔다고 이해했지만 이제서야 진정으로 이해하게 되었다.
- 그래서 문장마다 기억이 어떻게 연결되는거지? 했지만 이제는 kv를 캐시로 저장해두고 필요할 때마다 꺼내쓴다는걸 안다.
- 또한 MHA, MQA, GQA에서 관점과 검색이라는 단어로 표현했는데, Q를 나눈다는게 검색을 나눈다고 생각했지만 생각해보니 Q가 검색을 하는 대상이기 때문에 Q가 관점이고, KV가 ㅈ어보 공간이었다.
- 그렇기 때문에 MHA는 Q를 나누고(관점을 나누고), KV를 나눠서(정보 공간을 나눠서) 검색을 진행하고, MQA는 Q를 나눠서(관점을 나눠서), KV는 하나를 공유(단일 정보 공간)한다.
- GQA는 Q를 나눠서(관점을 나눠서) KV를 일부는 공유(정보 공간을 몇몇은 공유)한다.
