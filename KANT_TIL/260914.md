## 오늘 배운 것
- ollama의 structured_output은 모델이 지원하는 것이 아니라 디코더단에서 다음에 올 수 있는 토큰을 검사해서 강제하는 방식이었다.
- 그렇기 때문에 tool calling을 지원하지 않는 모델의 경우에도 structed_output은 강제될 수 있는 것이었다.
- `ollama`를 통해서 모델에 요청을 보내고 처리하는 것은 사실상 `ollama.Client`를 통해서 처리하는 것과 크게 다른 것이 없었다.
- 심지어 호출 가능한 함수까지 같기 때문에 리팩토링이 굉장히 중요하다.

## 왜 중요한가
- 보는 입장에서는 `ollama.Client`를 사용하는 코드만 보다가 갑자기 `ollama`를 사용하는 코드를 보면 당황할 수 있기 때문에 하나로 통일시킬 수 있다는게 다행이다.

## 코드/예시
```python
import ollama
from ollama import Client
# 이 코드와
ollama.ps()["models"]
# 이 코드의 동작은 동일하다.
client = Client(host="http://127.0.0.1:11434", timeout=180)
running = client.ps()["models"]
```

## 헷갈렸던 부분 & 해결
- 난 `ollama`를 써서 처리하면 `Client`를 사용하는 것과는 다른 방식으로 처리해야 하는줄 알았는데 알고보니 완전 같은 것이었다.
