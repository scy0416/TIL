## 오늘 배운 것
- 접두사를 붙이면서 학습하는 방식을 대조 학습(contrastive learning)이라고 한다.
- qdrant에서 위치를 `:memory:`로 하면 메모리에 저장되고, 종료되면 사라진다.
- 대신 특정 위치를 지정하면 그 위치에 저장되고, 클라우드로 쓰려면 연결 url과 api키를 넣어서 연결할 수 있다.
- qdrant에서는 Point단위로 넣고 관리한다.
- 콜렉션을 만들어서 관리할 수 있고, 클라우드 환경에서는 strict모드로 생성되어서 필터링이 기본적으로는 안된다.
- `retrieve`는 코사인 유사도를 구하는게 아니라 id로 가져오는거다.
- `query_point`가 코사인 유사도를 이용한다.
- `models`에 뭐가 겁나 많고, `models.Filter`에 `must`를 설정하면 모든 조건을 만족하는 것이고, `should`는 하나 이상 만족, `must_not`은 설정한 조건 제외다.
- 상세한 조건은 `models.FieldCondition`을 통해서 조건을 설정할 수 있고, `models.MatchValue`를 통해서 정확한 값을 매칭하도록 할 수 있다.
- 이외에도 다른거 많다.
- `client.scroll`을 통해서 페이지네이션을 할 수 있다.
- ann은 근사 최근접 이웃으로 많은 데이터 중에서 어떤 점과 가장 가까운 점들을 빠르게 찾는 기법이다.
- 정확도를 포기하고 속도를 챙긴다.
- FAISS에서 사용해볼 수 있고, HNSW알고리즘이 있다.
- FAISS에서는 qdrant처럼 Point같은 관리를 위한 단위가 없이 인덱스에서 벡터만 저장하고 있다.
- 그렇기 때문에 청크 데이터 및 메타 데이터를 따로 관리하고 있어야 한다.
- 기본적으로 `IndexFlatIP`는 코사인 유사도로 벡터를 검색하는 인덱스고, `IndexHNSWFlat`는 ann을 사용한다.
- 단, `IndexIDMap`를 사용해서 인덱스랑 ID를 매핑하도록 할 수 있다.
- 이를 통해서 따로 관리하는 청크에서 내용을 확인할 수 있다.

## 왜 중요한가
- 실제 RAG에서 가장 중요한 벡터 데이터베이스를 사용해보는 영역이기 때문에 중요하다.
- 심지어 벡터 데이터베이스를 두 개를 사용해봤다.

## 코드/예시
```python
# qdrant 클라이언트 사용 예제
from uuid import NAMESPACE_URL, uuid5
from qdrant_client import QdrantClient, models
from embedding_io import load_chunks, load_vectors, load_model
from dotenv import load_dotenv
import os

load_dotenv()

chunks = load_chunks()
vectors = load_vectors(chunks)

client = QdrantClient("...", api_key=os.getenv("QDRANT_API_KEY"))
collection = "kant_saved_e5"
if not client.collection_exists(collection):
    client.create_collection(
        collection_name=collection,
        vectors_config=models.VectorParams(
            size=int(vectors.shape[1]),
            distance=models.Distance.COSINE,
        ),
    )

print(client.count(collection).count)

points = []
for chunk, vector in zip(chunks, vectors):
    point = models.PointStruct(
        id=str(uuid5(NAMESPACE_URL, chunk["chunk_id"])),
        vector=vector.tolist(),
        payload=chunk,
    )
    points.append(point)

client.upsert(collection, points=points, wait=True)
print(client.count(collection).count)

client.create_payload_index(
    collection_name=collection,
    field_name="metadata.status",
    field_schema=models.PayloadSchemaType.KEYWORD,
    wait=True,
)

model = load_model()
question = "출장 숙박 비용 한도와 필요한 증빙은?"
query = model.encode("query: "+question, normalize_embeddings=True)

current_filter = models.Filter(
    must=[
        models.FieldCondition(
            key="metadata.status",
            match=models.MatchValue(value="current"),
        )
    ]
)

hits = client.query_points(
    collection,
    query=query.tolist(),
    query_filter=current_filter,
    with_payload=True,
).points
print(hits)
```

from rag_core import read_documents, chunk_documents
from embedding_io import load_chunks, load_vectors, load_model
import faiss
import numpy as np
import hashlib

def make_number(text):
    digest = hashlib.sha256(text.encode("utf-8")).digest()
    return int.from_bytes(digest[:8], "big") & 0x7FFFFFFFFFFFFFFF

chunks = load_chunks()
#stores = {chunk["chunk_id"]: chunk for chunk in chunks}
stores = {make_number(chunk["chunk_id"]): chunk for chunk in chunks}
vectors = load_vectors(chunks)
model = load_model()

d = vectors.shape[1] # dimension
nb = 100 # database size
nq = 100 # nb of queries
question = "출장 숙박 비용 한도는 8만원인가요?"
query = model.encode(["query: "+question], normalize_embeddings=True)

index = faiss.IndexIDMap(faiss.IndexFlatIP(d))
hnsw_index = faiss.IndexHNSWFlat(d, 16, faiss.METRIC_INNER_PRODUCT)
hnsw_index = faiss.IndexIDMap(hnsw_index)

chunk_ids = np.array([make_number(chunk["chunk_id"]) for chunk in chunks])
#index.add_with_ids(chunk_ids, vectors)
index.add_with_ids(vectors, chunk_ids)
hnsw_index.add_with_ids(vectors, chunk_ids)

scores, I = index.search(query, 3)
for s, i in zip(scores[0], I[0]):
    if i == -1:
