  - 딥러닝이 대부분의 문제를 해결하는데 있어 탁월하지만 꼭 모든 문제에 딥러닝을 사용하는게 좋은 것은 아니다.
  - 특징 설계는 원본 데이터를 모델이 이해하기 쉬운 숫자 형태로 변환하는 작업이다.
  - 딥러닝은 모델이 직접 원본데이터에서 유용한 표현을 찾아간다.
  - 딥러닝이 적합한 문제는 데이터가 많고, 입력이 복잡하며, 비선형 관계가 강하고, end-to-end 학습이 유리한 문제이다.
  - 반대로 적합하지 않고 굳이인 경우는 데이터가 너무 적고, 문제 규칙이 매우 명확하고, 해석 가능성이 중요하고, 계산자원이 부족하거나 빠른 베이스라인이 필요한 경우이다.
- 딥러닝 기초1-2
  - 학습에 사용하는 데이터들을 데이터셋이라고 하고, 학습을 위해서 batch단위로 꺼내는걸 DataLoader라고 한다.
  - 손실 함수는 문제 유형에 따라 다른데, 회귀는 `MSELoss`, 이진 분류는 `BCEWithLogitsLoss`, 다중 분류는 `CrossEntropyLoss`를 사용한다고 한다.
  - 학습을 진행하는 기본적인 스텝은 다음과 같다.
    1. optimizer.zero_grad()
    2. preds = model(batch_x)
    3. loss = loss_fn(preds, batch_y)
    4. loss.backward
    5. optimizer.step()
  - 루프는 train loop와 validation loop으로 구분되며, train loop에서는 파라미터가 변하고, validation loop에서는 파라미터가 변하지 않는다.
- 딥러닝 기초1-3
  - 딥러닝 모델을 만들기 위해서는 일단 문제 유형을 정해야 한다.
  - 기본적으로 회귀, 이진 분류, 다중 분류가 있고, 각 유형에 따라서 모델의 출력 결과도 달라지게 된다.
    - 회귀: 필요한 개수의 실수값 출력
    - 이진 분류: logit 1개 출력
    - 다중 클래스 분류: class 개수만큼 logit 출력
  - 이진 분류에서 사용하는 `BCEWithLogitsLoss`는 손실함수이면서 시그모이드도 같이 처리해준다.
  - 딥러닝에서는 데이터 유형에 따라서 입력할 텐서의 shape가 달라진다.
    - Tabular형(표 데이터): `[batch_size, feature_dim]`
    - 사진 데이터: `[batch_size, channels, height, width]`
    - 텍스트 토큰 ID: `[batch_size, sequence_length]`
    - 텍스트 임베딛: `[batch_size, sequence_length, embedding_dim]`
    - 시계열: `[batch_size, sequence_length, feature_dim]`
  - 데이터 형식에 따라서 기준이 되는 모델이 있다.
    - 표 데이터: MLP
    - 이미지 데이터: CNN
    - 시퀀스 데이터: RNN/LSTM
    - 긴 텍스트/문맥: Transformer
- 딥러닝 기초1-4
  - 딥러닝 학습에는 보통 비슷한 흐름이 있다.
```plaintext
import
-> 설정값 정의
-> 데이터 준비
-> 모델 정의
-> loss / optimizer 정의
-> train 함수
-> validate 함수
-> epoch 반복
-> 로그 출력
-> 모델 저장
```
  - train loop와 validation loop은 섞어서 쓰면 안된다.
    - 이는 `optimizer.step()`에서 검증 데이터로 모델이 학습되기 때문인데, validation loop에서의 그래디언트가 누적되어서 그런 것이다.
- 딥러닝 기초2-1
  - 딥러닝에서 텐서를 볼 때에는 값 자체보다는 shape, dtype, device를 확인해야 한다.
  - 텐서는 차원별로 생각할 수 있고, 차원별로 0차원은 스칼라, 1차원은 벡터, 2차원은 행렬, 3차원은 행렬들의 묶음으로 볼 수 있다.
  - 텐서에는 shape, ndim, dtype, device 속성이 있고, 이는 각각 텐서의 모양, 텐서의 차원 수, 텐서의 자료형, 텐서가 저장된 장치를 의미한다.
  - 텐서는 간단하게 `torch.tensor()`를 통해서 만들 수 있다.
- 딥러닝 기초2-2
  - `unsqueeze(n)`을 통해서 n번째 위치에 차원을 추가할 수 있다.
  - 이 때에 (4)였다면 `unsqueeze(0)`을 실행하면 (1, 4)가 된다.
  - 반대로 `squeeze(n)`은 크기가 1인 차원을 삭제하며, (1, 4)에 대해서 `squeeze(0)`을 하면 (4)가 된다.
  - 위치를 지정하지 않으면 대상 텐서의 모든 크기가 1인 차원을 없애버린다.
  - 브로드캐스팅이란 shape가 다른 텐서들끼리 연산을 할 때에 규칙에 따라서 크기를 조정해주는 기능이다.
  - 예를 들어 (4, 3)과 (3)을 연산한다면 (3)을 (1, 3)으로 늘려준 다음 (4, 3)으로 크기를 맞춰서 연산을 진행하게 된다.
  - 브로드캐스팅은 기본적으로 크기가 맞는 차원들끼리 매칭해서 나머지를 늘리고 맞춰서 연산을 한다.
  - 여기에서 크기를 맞추는 것은 그 차원의 크기가 1일 때에만 가능하고, 1이 아닌 다른 값이라면 브로드캐스팅을 지원해주지 않는다.
  - 차원이 증가하는 쪽은 항상 왼쪽이다.
  - 브로드캐스팅을 통해서 의도하지 않은 결과를 만들어낼 수 있다.
    - 예를 들어 (4, 1)와 (4)짜리 텐서를 연산할 때 결과는 (4, 4)가 되는데, 이는 (4)가 (1, 4)로 차원이 들고 크기가 1인 차원들이 4로 늘어나 (4, 4)와 (4, 4)의 연산이 되어 결과 또한 (4, 4)가 된다.

## 코드/예시
```python
# 파이토치 학습 루프 스켈레톤
import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset, random_split

torch.manual_seed(42)

# 1. 예제 데이터 생성
X = torch.randn(200, 4)
true_w = torch.tensor([[2.0], [-1.0], [0.5], [3.0]])
y = X @ true_w + 0.1 * torch.randn(200, 1)

# 2. Dataset / DataLoader 구성
dataset = TensorDataset(X, y)
train_dataset, valid_dataset = random_split(dataset, [160, 40])

train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
valid_loader = DataLoader(valid_dataset, batch_size=64, shuffle=False)

# 3. device 설정
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# 4. 모델 정의
model = nn.Sequential(
    nn.Linear(4, 16),
    nn.ReLU(),
    nn.Linear(16, 1),
).to(device)

# 5. 손실 함수와 옵티마이저 정의
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.05)

# 6. train loop
def train_one_epoch(model, dataloader, loss_fn, optimizer, device):
    model.train()
    total_loss = 0.0

    for batch_x, batch_y in dataloader:
        batch_x = batch_x.to(device)
        batch_y = batch_y.to(device)

        optimizer.zero_grad()
        preds = model(batch_x)
        loss = loss_fn(preds, batch_y)
        loss.backward()
        optimizer.step()

        total_loss += loss.item() * batch_x.size(0)

    return total_loss / len(dataloader.dataset)

# 7. validation loop
@torch.no_grad()
def validate(model, dataloader, loss_fn, device):
    model.eval()
    total_loss = 0.0

    for batch_x, batch_y in dataloader:
        batch_x = batch_x.to(device)
        batch_y = batch_y.to(device)

        preds = model(batch_x)
        loss = loss_fn(preds, batch_y)

        total_loss += loss.item() * batch_x.size(0)

    return total_loss / len(dataloader.dataset)

# 8. epoch 반복
for epoch in range(1, 6):
    train_loss = train_one_epoch(model, train_loader, loss_fn, optimizer, device)
    valid_loss = validate(model, valid_loader, loss_fn, device)

    print(f"Epoch {epoch} | train_loss={train_loss:.4f} | valid_loss={valid_loss:.4f}")
```
