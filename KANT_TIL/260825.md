- 딥러닝 기초6-1
  - 계산 그래프란 값이 어떤 연산들을 거쳐서 만들어졌는지 표현한 그림이다.
  - 계산 그래프는 backward할 때 사용할 수 있다.
  - `requires_grad`가 참인 텐서들은 연산 시에 `grad_fn`을 가지로 있는데, 이전 연산에 대한 정보들이다.
  - 이제 backward를 하면 그 정보들을 타고 올라가서 grad를 계산하게 된다.
  - loss가 스칼라값이어야 정상적으로 backward를 호출하는 것이 가능하다.
  - 만약 그렇지 않고 loss가 여러 값이라면 일부가 누락되는 일이 발생할 것이다.
- 딥러닝 기초6-2
  - backward를 하면 보통 학습 대상 leaf tensor의 `.grad`에 gradient가 저장된다.
  - `requires_grad`는 연산을 추적하겠다는 신호로 이 값이 참이어야지 연산을 추적한다.
  - 그렇지 않다면 backward를 할 수가 없다.
  - leaf tensor는 해당하는 텐서가 다른 텐서들의 연산을 통해서 만들어지지 않은 텐서들이고, non-leaf tensor는 그 텐서가 다른 텐서들의 연산을 통해서 만들어진 텐서이다.
  - Autograd에서는 이 중에서 leaf tensor이면서 requires_grad=True인 텐서들에 대해서만 gradient를 계산한다.
  - `nn.Linear`로 연산하면 grad가 계산 가능한 것도 `nn.Linear`의 파라미터들은 기본적으로 `requires_grad`값이 참이기 때문이다.
  - `with torch.no_grad():`블럭에서 진행된 연산들은 gradient를 연산하지 않고, 이 특성 때문에 평가 코드에서 사용된다.
  - 만약 평가 코드에서 gradient를 계산한다면 연산 속도와 메모리 사용량이 오르게 된다.
  - `detach()`는 값은 사용하지만 그래프를 끊는다.
  - 계산되는 와중에 `detach()`를 한다고 해서 결과 값이 변하거나 하지는 않는다.
  - 하지만 그래프 상으로는 그 부분이 끊긴 것이기 대문에 최종 non-leaf tensor를 사용해서 grad 계산을 한다면 계산 그래프 상에서 `detach()`를 진행한 이후의 leaf tensor까지만 grad 계산이 된다.
- 딥러닝 기초6-3
  - `.grad`는 backward를 시행하기 전까지 없다.
- 딥러닝 기초6-4
  - grad는 기본적으로 누적되기 때문에 `optimizer.zero_grad()`를 통해서 매 step마다 초기화를 해줘야 하는데, 엄밀히는 0텐서가 아니라 아예 None으로 비워버린다.
  - `optimizer.step()`은 각 파라미터에 저장된 `.grad`를 바탕으로 실제 파라미터를 업데이트하며, 이 때, 처리하는 파라미터들은 optimizer를 초기화할 대 등록되었던 파라미터들에 대해서 처리한다.
  - 텐서에 대해서 `item()`을 통해서 상세한 값을 추출하면 그 땐 원시 데이터타입이기 때문에 backward가 불가능하니 조심해야 한다.
- 딥러닝 기초6-5

  - 둘의 차이는 Dropout, BatchNorm의 동작 방식이 서로 달라진다는 것이다.
  - grad를 계산하지 않는다거나 하는 차이는 없다고 한다.
  - 그렇기 때문에 `torch.no_grad()`를 통해서 따로 grad 계산을 제한해줘야 한다.
  - detach는 그래프를 끊는 역할이기 때문에 안전한 로깅을 위해서 사용할 수 있다.

## 왜 중요한가
- 실제로 어떤 방식으로 gradient가 계산되는지에 대한 내용이었다.
- 이 내용을 모른다면 실제로 어떻게 검산해야할지도 알 수 없고, 문제가 생긴 부분을 디버깅 하기 곤란해질 수도 있다.
- 특히 detach를 통한 계산 그래프의 차단을 모르면 시간을 꽤 많이 허비할 수도 있을 것 같다.

## 느낀점
- 오늘 한 것들은 사실 계속 해오던 것들이기 때문에 어렵지는 않았다.
- 하지만 강의의 양 자체가 많아서 실습을 하는데 벅차는 감이 있긴 했다.
- 그래도 어제 실습하다가 알게 된 것들에 대해서 더 자세하게 알려주는 강의여서 마음에는 든다.

# 계산 그래프 확인하는 예제
import torch

w = torch.tensor(3.0, requires_grad=True)
x = torch.tensor(2.0)
b = torch.tensor(1.0)

z = x * w + b
loss = z ** 2

# loss를 기준으로 w의 gradient를 계산합니다.
loss.backward()

# w.grad에는 loss가 w에 대해 얼마나 민감한지 저장됩니다.
print("w:", w)
print("w.grad:", w.grad)
```

# step 후에 파라미터가 변하는걸 확인하는 예제
def check_one_step_update(model, optimizer, criterion, x, y):
    """
    한 번의 학습 step에서 파라미터가 실제로 바뀌는지 확인합니다.
    """
    # 첫 번째 파라미터를 복사합니다.
    first_param_before = next(model.parameters()).detach().clone()

    optimizer.zero_grad()
    pred = model(x)
    loss = criterion(pred, y)
    loss.backward()
    optimizer.step()

    first_param_after = next(model.parameters()).detach().clone()

    print("loss:", loss.item())
    print("parameter changed?:", not torch.allclose(first_param_before, first_param_after))

check_one_step_update(model, optimizer, criterion, x, y)
```

# 안전한 valid step 예제
def validation_step(model, criterion, x, y):
    """
    하나의 validation batch에 대해 loss를 계산합니다.
    평가에서는 파라미터를 업데이트하지 않으므로 no_grad를 사용합니다.
    """
    # 평가 모드로 전환합니다.
    model.eval()

    # gradient 추적을 끕니다.
    with torch.no_grad():
        pred = model(x)
        loss = criterion(pred, y)

    # 기록용 Python float로 반환합니다.
    return loss.item()
```

# 표 데이터 Custom Dataset 예제
import torch
from torch.utils.data import Dataset

class TabularDataset(Dataset):
    """
    feature Tensor와 label Tensor를 받아
    idx번째 샘플을 반환하는 간단한 표 데이터 Dataset입니다.
    """
    def __init__(self, features, labels):
        """
        features:
            shape가 (num_samples, num_features)인 Tensor입니다.

        labels:
            shape가 (num_samples,)인 class label Tensor입니다.
        """
        # 샘플 개수가 같은지 확인합니다.
        assert len(features) == len(labels), "features와 labels의 샘플 수가 다릅니다."

        self.features = features
        self.labels = labels

    def __len__(self):
        """
        Dataset 전체 샘플 수를 반환합니다.
        """
        return len(self.features)

    def __getitem__(self, idx):
        """
        idx번째 feature와 label을 반환합니다.
        """
        x = self.features[idx]
        y = self.labels[idx]
        return x, y
```

## 헷갈렸던 부분 & 해결
- leaf 텐서와 non-leaf텐서, grad가 계산되는 텐서의 구분이 잘 되지 않았다.
- 처음에는 leaf 텐서와 non-leaf텐서만으로 구분하는건가 생각했지만 더 알아보니 leaf텐서면서 requires_grad가 참이어야 하는거였다.
- 어제가지만해도 `model.parameters()`해가지고 처리를 하려고 했는데, 이제는 `model.weight`를 통해서 처리를 하면 된다는걸 알고 있다.
- 또한 `model.parameters()`를 통해서 접근 가능한 텐서 두 개는 각각 weight, bias이고, `model.grad`를 통해서 weight, bias에 대한 grad에 접근할 수 있음을 알게 되었다.
- 어제가지는 `model.parameters()`하면 나오는 두 개의 텐서들 중에서 bias에 해당하는걸 grad라고 착각했었다.
