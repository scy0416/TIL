- 딥러닝 기초7-3
  - 이미지 데이터는 크기나 학습에 적합하지 않은 형태를 가지고 있을 수 있기 때문에 전처리를 해줘야 한다.
  - 이런 전처리는 PyTorch에서는 transform으로 구성한다.
  - 여러 개의 transform은 `Compose`를 통해서 파이프라인으로 연결한다.
  - 이미지 관련 전처리와 증강은 다음과 같은 것들이 존재한다.
    - `Resize`: 이미지의 크기를 맞춘다.
    - `ToTensor`: 이미지를 텐서의 형태로 변환한다.
    - `Normalize`: 채널별 정규화를 한다.
    - `RandomHorizontalFlip`: 증강을 목적으로 이미지를 랜덤하게 뒤집는다.
  - `ToTensor`는 채널의 순서가 PyTorch에서 다루는 텐서와 다른 형태의 이미지를 PyTorch에서 다루는 방식의 텐서로 채널을 변경하는 것이다.
  - 일반적으로 PyTorch에서의 이미지 배치는 `(batch_size, channels, height, width)`일 것을 기대한다.
  - 정규화는 값의 범위를 -1에서 1사이로 바꿔서 특정 스케일에 과하게 민감해지는 것을 줄인다.
  - 이미지를 뒤집거나 처리해서 변화시키는 전처리는 학습의 품질을 높이기 위해서 사용하는 전처리로 이러한 전처리는 valid 및 test 에서는 필요없기 때문에 구분해서 transform을 형성해야 한다.
  - 커스텀한 데이터셋을 직접 만들어서 transform을 받아서 불러올 때에 이미지가 전처리를 실행하도록 하는 것도 가능하다.
- 딥러닝 기초7-4
  - 데이터셋을 train, valid, test로 분할해서 사용할 때에 train 데이터셋은 shuffle을 참으로 설정해서 학습 시에 랜덤한 순서로 학습될 수 있도록 한다.
  - 이는 학습 데이터셋은 학습에 의미가 있기 때문에 매번 같은 순서로 학습을 하면 모델이 순서 자체에 적응을 해버릴 수 있기 때문이다.(과정합)
  - valid, test는 섞지 않는 이유는 그 둘은 모델을 평가하는데에 의의가 있기 때문에 섞을 이유가 없다.
  - `random_split`을 이용하면 데이터셋을 여러 부분으로 분할 하는 것이 가능한데, 이 때에 반환되는 값은 실제 데이터가 아니라 랜덤하게 뽑힌 indices를 가지며, 원본 데이터셋에 대한 참조를 가지고 있는 Subset이다.
  - 이걸 받은 dataloader는 Dataset과 마찬가지로 `__len__`, `__getitem__`을 이용해서 처리하는 것이다.
  - split의 결과를 유지하기 위해서 `torch.Generator().manual_seed()`를 사용할 수 있다.
  - 앞서 train, valid, test는 각각 서로 다른 transform을 적용해야 한다고 했는데, 스플릿한 서브셋들은 원본 데이터셋을 참조하는 상태이기 때문에 원본 데이터셋에 transform이 적용되는 방식이라면 transform을 변경하는 방식으로는 train, valid, test를 구분하는 것이 불가능하다.
  - 그렇기 때문에 각각을 위한 transform을 따로 만들어서 각각을 위한 데이터셋을 또 따로 만들어야 한다.

# 전처리 과정을 포함하는 커스텀 데이터셋 예제
import torch
from torch.utils.data import Dataset

class DummyImageDataset(Dataset):
    """
    이미지 Dataset의 구조를 연습하기 위한 더미 Dataset입니다.
    실제 프로젝트에서는 image_paths를 받아 파일을 읽는 방식으로 바뀝니다.
    """
    def __init__(self, images, labels, transform=None):
        assert len(images) == len(labels)
        self.images = images
        self.labels = labels
        self.transform = transform

    def __len__(self):
        return len(self.images)

    def __getitem__(self, idx):
        image = self.images[idx]
        label = self.labels[idx]

        # transform이 있으면 image에 적용합니다.
        if self.transform is not None:
            image = self.transform(image)

        return image, label
```

# split 별 transform 적용 예제
import torch
from torch.utils.data import Dataset, TensorDataset, random_split

class SubsetWithTransform(Dataset):
    def __init__(self, base_dataset, indices, transform=None):
        self.base_dataset = base_dataset
        self.indices = list(indices)
        self.transform = transform

    def __len__(self):
        return len(self.indices)

    def __getitem__(self, idx):
        x, y = self.base_dataset[self.indices[idx]]
        if self.transform is not None:
            x = self.transform(x)
        return x, y

# 실제 이미지 프로젝트에서는 transform=None인 원본 Dataset을 준비합니다.
X = torch.arange(100 * 6, dtype=torch.float32).reshape(100, 6)
y = torch.arange(100) % 3
raw_dataset = TensorDataset(X, y)

split_generator = torch.Generator().manual_seed(42)
train_part, valid_part, test_part = random_split(
    raw_dataset,
    [70, 15, 15],
    generator=split_generator,
)

# 예시용 transform입니다. 실제 이미지라면 train_transform과 valid_transform을 넣습니다.
train_transform = lambda x: x + torch.rand_like(x) * 0.01
valid_transform = lambda x: x
test_transform = lambda x: x

train_dataset = SubsetWithTransform(raw_dataset, train_part.indices, train_transform)
valid_dataset = SubsetWithTransform(raw_dataset, valid_part.indices, valid_transform)
test_dataset = SubsetWithTransform(raw_dataset, test_part.indices, test_transform)

print(len(train_dataset), len(valid_dataset), len(test_dataset))
print("valid sample is stable:", torch.equal(valid_dataset[0][0], valid_dataset[0][0]))
```
