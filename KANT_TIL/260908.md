## 오늘 배운 것
- 딥러닝 심화7-1
  - 텍스트 분류 모델은 무엇을 입력 받을 것이며, 어떤 라벨을 예측할 것이고, 성공 기준을 뭐로 판단할지 정해야 한다.
  - 문제 정의 5요소는 다음과 같다.

| 항목        | 질문                                | 예시                                |
|-------------|-------------------------------------|-------------------------------------|
| 입력        | 모델이 읽는 텍스트는 무엇인가?      | 뉴스 제목, 리뷰, 고객 문의          |
| 출력        | 모델이 예측해야 하는 것은 무엇인가? | topic, sintiment, intent            |
| 라벨 규칙   | 각 라벨은 어떤 의미인가?            | `sports`는 스포츠 기사 제목         |
| 성공 기준   | 어떤 metric을 중요하게 볼것인가?    | Macro-F1, Accuracy, 클래스별 Recall |
| 실패 리스크 | 모델이 틀리면 어떤 문제가 생기나?   | 잘못된 라우팅, 민감 문의 누락       |
  - Label schema는 모델이 예측할 수 있는 라벨 목록과 의미이다.
  - Label imbalance는 클래스 간의 균형이 안맞는 상태로 다수 클래스의 경우에는 모델이 자주 맞힐 가능성이 크다.
  - 다수 클래스의 특성을 외우는 등의 과적합 현상이 발생할 수 있다.
  - 그러면 샘플 수가 적은 소수 클래스는 무시할 수 있고, 다수 클래스를 맞추는 것 만으로도 모델의 전체 Accuracy는 높아질 수 있다.
  - 이를 방지하기 위해서 Macro-F1을 사용해서 각 클래스별로 성능 지표에 동등한 비율로 반영을 한다.
  - 데이터 점검을 하기 위해서 확인할 것들은 다음과 같다.
    - 결측: 입력 또는 label이 비어있는 샘플을 확인한다.
    - 중복: 같은 문장이 여러 split에 걸쳐 들어가면 과대평가될 수 있다.
    - 라벨 분포: 특정 라벨이 지나치게 많은 Label imbalance를 확인한다.
    - 누수: 입력에 정답이 들어있는 등의 데이터 누수를 확인한다. 
- 딥러닝 심화7-2
  - `DatasetDict`는 허깅페이스에서 제공하는 데이터셋을 딕셔너리 형태로 관리하는 자료형이다.
  - train/valid/test 등으로 나뉘어서 관리하는 데이터셋을 한 번에 관리할 수 있다.
  - 모델의 학습을 위해서 라벨을 문자열에서 정수형 id로 변환하는 과정을 거쳐야 한다.
  - 이를 위해서 config.json에서는 `label2id`와 `id2label`이라는 변환을 위해서 대응하는 라이브러리를 제공한다.
- 딥러닝 심화7-3
  - 문자열은 학습을 위해서 토크나이저를 통해서 토큰id로 바뀌어야 한다.
  - 문자열 Label은 Label id로, 문자열 입력은 토큰 id로 변환되어야 학습에 사용할 수 있는 것이다.
- 딥러닝 심화7-4
- 딥러닝 심화7-5
  - Metric을 선택할 때에 단순히 Accuracy만을 선택해서는 안된다.
  - 모델의 특성이나 상황에 따라서 적절하게 선택해야 하며, 다음과 같은 지표들을 사용할 수 있다.

| 지표      | 질문                                          | 중요한 상황                    |
|-----------|-----------------------------------------------|--------------------------------|
| Precision | 모델이 클래스라고 한 것들이 얼마나 정확한가?  | 잘못된 경고를 줄이고 싶은 경우 |
| Recall    | 실제 이 클래스인 것들을 얼마나 놓치지 않았나? | 위험 사례를 놓치면 안될 때     |
| F1        | Pricision과 Recall의 균형이 어떤가?           | 둘 다 중요할 때                |
  - Macro-F1은 각 클래스에 대한 F1을 계산한 뒤에 단순 평균을 구하는 것으로, 소수 클래스더라도 결과적으로 같은 비중으로 반영될 수 있다.
- 딥러닝 심화7-6
  - TrainingArguments는 학습 실행 조건을 한 곳에 모아둔 설정 객체이다.
  - 들어가는 값들은 다음과 같은 것들이 있다.
    - batch size
    - learning rate
    - epoch
    - logging 간격
    - evaluation 간격
    - checkpoint 저장 정책
  - 이는 만드는 사람에 따라서 내용물이 달라질 수 있으니 유의해야 한다.
- 딥러닝 심화7-7
  - fine-tuning은 사전 학습 모델을 특정 문제에 맞게 업데이트하는 과정으로 실행 흐름은 다음과 같다.
    - train()
    - evaluate()
    - checkpoint저장
    - best model 선정
  - 체크포인트를 저장할 때에는 모든 과정을 저장하고, best checkpoint와 final model을 구분해서 저장하도록 한다.
  - 그러면 이후에 모델을 재현하거나 운영하는데 편하다.
  - 모델 전체를 저장할 때에는
    - 모델의 가중치와 config를 저장한다.
    - 토크나이저 설정을 저장한다.
    - 저장된 경로로부터 불러와 동일한 입력 처리를 해본다.
- 딥러닝 심화7-8
  - Metric는 숫자를 통해서 모델의 성능을 간단하게 표현하는 것으로, 정확하게 무엇을 어떻게 고쳐야하는지에 대해서는 알기 쉽지 않다.
  - Error Analysis는 틀린 샘플들을 직접 확인하고 라벨 경계, 데이터 품질, 모델 한계, 전처리 문제 등을 찾아가는 과정이다.
  - 전체 흐름은 다음과 같다.
    - prediction: 모델 예측 label과 confidence를 저장한다.
    - compare: 정답과 예측을 비교해 오류를 필터링한다.
    - pattern: 특정 label 쌍, 짧은 문장, 애매한 표현을 분석한다.
    - action: 데이터 보강, 라벨 정비, metric 수정으로 연결한다.
  - Confidence는 모델이 정답을 정할 때의 확신도로, 모델이 정답으로 예측했을 때의 스코어이다.
  - 값의 크기에 따라서 다르게 해석할 수 있다.
    - 높은 확신 오류: 모델이 잘못된 패턴을 강하게 배웠다.
    - 낮은 확신 오류: 문장이 애매하거나 라벨 경계가 불분명하다.
  - 이 유형들에 대한 샘플을 뽑아 바르게 검토할 수 있다.
  - fine-tuning 리포트는 다른 사람이 보고서 재현 및 개선하는데 활용할 수 있는 문서이다.
  - fine-tuning 리포트에 들어가는 내용들은 다음과 같다.
    - 문제 정의: 입력, 출력, 라벨, 성공 기준
    - 실험 설정: 모델, 토크나이저, split, seed, hyperparameter
    - 평가 결과: metric, confusion matrix, 오류 사례
    - 한계와 개선: 데이터와 모델의 한계, 다음 실험 계획

## 코드/예시
```python
# 실제 KLUE YNAT 데이터셋을 다중 분류하는 에제
from pathlib import Path
import inspect
import json

import numpy as np
import pandas as pd
import torch
import transformers

from datasets import load_dataset
from sklearn.metrics import accuracy_score, classification_report, f1_score

from transformers import (
    AutoModelForSequenceClassification,
    AutoTokenizer,
    DataCollatorWithPadding,
    EvalPrediction,
    Trainer,
    TrainingArguments,
    set_seed,
)



# =========================================================
# 1. 기본 설정
# =========================================================
DATASET_ID = "klue/klue"
DATASET_CONFIG = "ynat"
TEXT_COL = "title"
LABEL_COL = "label"
MODEL_ID = "klue/roberta-small"

PROJECT_DIR = Path("artifacts/ynat_finetuning")
PROJECT_DIR.mkdir(parents=True, exist_ok=True)

SEED = 42
MAX_LENGTH = 128
NUM_EPOCHS = 3

set_seed(SEED)

print("transformers:", transformers.__version__)
print("torch:", torch.__version__)
print("CUDA available:", torch.cuda.is_available())



# =========================================================
# 2. 데이터셋 로딩 + 라벨 정보 읽기
# =========================================================
dataset = load_dataset(DATASET_ID, DATASET_CONFIG)

# YNAT의 label 컬럼에는 클래스 수와 클래스 이름이 들어 있습니다.
label_feature = dataset["train"].features[LABEL_COL]

label_names = label_feature.names
num_labels = label_feature.num_classes

# 예: 0 -> "IT과학"
id2label = dict(enumerate(label_names))

# 예: "IT과학" -> 0
label2id = {
    name: idx
    for idx, name in id2label.items()
}

assert num_labels == 7, (
    f"YNAT의 라벨 수를 확인하세요: {num_labels}"
)

print(dataset)
print("num_labels:", num_labels)
print("id2label:", id2label)

# 학습·검증 데이터의 실제 라벨 값도 확인합니다.
for split in ["train", "validation"]:
    labels = np.asarray(dataset[split][LABEL_COL])

    assert np.all((0 <= labels) & (labels < num_labels)), (
        f"{split}: 라벨은 0~{num_labels - 1} 범위여야 합니다."
    )



# =========================================================
# 3. 토크나이저 + 전처리
# =========================================================
tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)



def tokenize_batch(examples):
    encoded = tokenizer(
        examples[TEXT_COL],
        truncation=True,
        max_length=MAX_LENGTH,
        padding=False,  # 실제 패딩은 배치를 만들 때 수행합니다.
        return_token_type_ids=False,
    )

    # 원본의 "label"을 모델에 전달할 "labels"로 넣습니다.
    encoded["labels"] = examples[LABEL_COL]

    return encoded



# 원본의 title, label, guid, url, date 등을 제거하고,
# 모델 입력과 labels만 남깁니다.
# 원본 dataset은 그대로 유지됩니다.
tokenized_dataset = dataset.map(
    tokenize_batch,
    batched=True,
    remove_columns=dataset["train"].column_names,
)

# 배치 내 가장 긴 문장에 맞춰 패딩합니다.
data_collator = DataCollatorWithPadding(
    tokenizer=tokenizer,
    padding=True,
    return_tensors="pt",
)



# =========================================================
# 4. 핵심 수정: 7개 클래스를 출력하는 모델을 새로 생성
# =========================================================
# 기존 model의 config 값만 바꾸지 않고 모델을 다시 불러옵니다.
model = AutoModelForSequenceClassification.from_pretrained(
    MODEL_ID,
    num_labels=num_labels,
    id2label=id2label,
    label2id=label2id,
    problem_type="single_label_classification",
    torchscript=False,
    return_dict=True,
)

# config뿐 아니라 실제 분류층의 출력 크기도 확인합니다.
assert model.config.num_labels == num_labels
assert model.classifier.out_proj.out_features == num_labels

print("model num_labels:", model.config.num_labels)
print("classification output layer:", model.classifier.out_proj)



# =========================================================
# 5. 평가 함수
# =========================================================
def compute_metrics(eval_pred: EvalPrediction) -> dict[str, float]:
    logits = eval_pred.predictions

    # logits 외에 다른 출력이 함께 반환되는 경우에 대응합니다.
    if isinstance(logits, tuple):
        logits = logits[0]

    # logits: (샘플 수, 7)
    # predictions: (샘플 수,)
    predictions = np.argmax(logits, axis=-1)
    labels = eval_pred.label_ids

    return {
        "accuracy": float(
            accuracy_score(labels, predictions)
        ),
        "macro_f1": float(
            f1_score(
                labels,
                predictions,
                labels=np.arange(num_labels),
                average="macro",
                zero_division=0,
            )
        ),
    }



# =========================================================
# 6. TrainingArguments
# =========================================================
training_kwargs = dict(
    output_dir=str(PROJECT_DIR / "checkpoints"),

    # 학습 설정
    num_train_epochs=NUM_EPOCHS,
    learning_rate=2e-5,
    per_device_train_batch_size=16,
    per_device_eval_batch_size=32,
    weight_decay=0.01,
    optim="adamw_torch",

    # 체크포인트 저장 및 best model 선택
    save_strategy="epoch",
    save_total_limit=2,
    load_best_model_at_end=True,
    metric_for_best_model="macro_f1",
    greater_is_better=True,

    # 로그
    logging_strategy="steps",
    logging_steps=50,
    report_to="none",

    # 기타 설정
    seed=SEED,
    data_seed=SEED,
    dataloader_num_workers=0,

    # 데모에서는 혼합 정밀도를 사용하지 않습니다.
    fp16=False,
    bf16=False,
)

# 설치된 Transformers에서 지원하는 평가 인자명을 사용합니다.
args_parameters = inspect.signature(
    TrainingArguments.__init__
).parameters

strategy_key = (
    "eval_strategy"
    if "eval_strategy" in args_parameters
    else "evaluation_strategy"
)

training_kwargs[strategy_key] = "epoch"

training_args = TrainingArguments(**training_kwargs)



# =========================================================
# 7. Trainer도 새 모델로 다시 생성
# =========================================================
trainer_kwargs = dict(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset["train"],
    eval_dataset=tokenized_dataset["validation"],
    data_collator=data_collator,
    compute_metrics=compute_metrics,
)

# 현재 버전은 processing_class, 이전 버전은 tokenizer를 사용합니다.
trainer_parameters = inspect.signature(
    Trainer.__init__
).parameters

processor_key = (
    "processing_class"
    if "processing_class" in trainer_parameters
    else "tokenizer"
)

trainer_kwargs[processor_key] = tokenizer

trainer = Trainer(**trainer_kwargs)

# Trainer가 실제로 사용하는 장치입니다.
device = trainer.args.device

print("train columns:", tokenized_dataset["train"].column_names)
print("validation columns:", tokenized_dataset["validation"].column_names)
print("best model metric:", training_args.metric_for_best_model)
print("device:", device)



# =========================================================
# 8. 학습
# =========================================================
# 이전 2-class 모델의 체크포인트에서는 재개하지 않습니다.
train_result = trainer.train(resume_from_checkpoint=False)

print(train_result)
print("best checkpoint:", trainer.state.best_model_checkpoint)
print("best validation macro_f1:", trainer.state.best_metric)



# =========================================================
# 9. 검증 데이터 평가 + 샘플별 예측
# =========================================================
# 학습 종료 후 best model이 로드된 상태입니다.
# predict()로 지표와 예측을 함께 얻어 중복 평가를 피합니다.
prediction_output = trainer.predict(
    tokenized_dataset["validation"],
    metric_key_prefix="eval",
)

eval_result = prediction_output.metrics
print("validation results:", eval_result)

logits = prediction_output.predictions

if isinstance(logits, tuple):
    logits = logits[0]

pred_ids = np.argmax(logits, axis=-1)
true_ids = prediction_output.label_ids

# 클래스별 precision, recall, F1을 출력합니다.
report = classification_report(
    true_ids,
    pred_ids,
    labels=np.arange(num_labels),
    target_names=label_names,
    digits=4,
    zero_division=0,
)

print(report)



# =========================================================
# 10. 모델 / 토크나이저 / 지표 / 예측 / 리포트 저장
# =========================================================
# 같은 PROJECT_DIR로 재실행하면 아래 최종 결과 파일은 덮어씁니다.
best_model_dir = PROJECT_DIR / "best_model"

trainer.save_model(str(best_model_dir))
tokenizer.save_pretrained(str(best_model_dir))

# 학습·검증 지표 저장
metrics = {
    "train": train_result.metrics,
    "validation": eval_result,
}

(PROJECT_DIR / "metrics.json").write_text(
    json.dumps(metrics, ensure_ascii=False, indent=2),
    encoding="utf-8",
)

# 클래스별 분류 리포트 저장
(PROJECT_DIR / "classification_report.txt").write_text(
    report,
    encoding="utf-8",
)

# 검증 데이터의 샘플별 예측 저장
prediction_df = pd.DataFrame({
    "title": list(dataset["validation"][TEXT_COL]),
    "true_id": true_ids,
    "true_label": [id2label[int(i)] for i in true_ids],
    "pred_id": pred_ids,
    "pred_label": [id2label[int(i)] for i in pred_ids],
    "correct": true_ids == pred_ids,
})

prediction_df.to_csv(
    PROJECT_DIR / "validation_predictions.csv",
    index=False,
    encoding="utf-8-sig",
)

print("saved to:", PROJECT_DIR.resolve())
```
