## 오늘 배운 것
- 딥러닝 기초4-1
  - 활성화 함수 없이 MLP가 아무리 깊어져도 단일 아핀 변환이랑 다를게 없다.
  - ReLU같은 활성화 함수는 입력 공간을 여러 구간으로 나누어 서로 다른 계산을 할 수 있게 만들어서 공간에 대한 선의 표현력을 증가시킨다.
  - 활성화 함수는 입력층, 출력층을 제외한 은닉층들에 들어간다.
  - xor 케이스에서 활성화 함수 없는 모델은 loss가 0.693부근에 머물며, 이 값은 자연로그 `ln(2)`와 같다.
  - ReLU는 모델의 표현력을 증가시켜주지만 학습에 실패할 수 있으며, 이는 구조적으로 불가능한 것과는 다르다.
- 딥러닝 기초4-2
  - ReLU는 `max(0, x)`와 같아서 음수값을 0으로 만들어버린다.
  - ReLU는 양수 영역에서는 기울기가 1이고, 음수 영역에서는 기울기가 0이다.
  - 이는 양수영역에서는 그라디언트가 흐르고 음수에서는 0이 된다는 것이다.
  - ReLU는 음수를 0으로 만들기 때문에 특정 뉴런이 음수 값만 출력한다면 뒤에서 값들이 0이 되버리고, 그 뒤로는 학습 신호를 거의 받지 못하는 케이스가 발생할 수 있다.
  - 이러한 현상을 Dead ReLU라고 한다.
- 딥러닝 기초4-3
  - 이진 분류에서의 logit은 샘플 당 하나이다.
  - 출력 logit을 0~1사이의 값으로 만들어주기 위해서 sigmoid 함수가 사용된다.
  - 그 후 0.5와 같은 임계값(threshold)를 통해서 클래스를 구분한다.
  - sigmoid함수는 기본적으로 값이 작을수록 0에 가깝고, 클수록 1에 가깝게 처리해주어 0.5를 기준으로 구분하기 편하게 만들어준다.
  - 이진 분류에서의 loss함수는 `BCEWithLogitsLoss`인데, 이름에 나오듯이 logit을 사용해서 계산을 하며, 내부적으로 sigmoid를 따로 처리한다.
  - 그렇기 때문에 sigmoid를 처리한 값을 넣어서는 안된다.
  - 내부적으로 한 번 더 처리해서 두 번 처리한 값으로 loss를 비교하게 된다.
  - 또한 `BCEWithLogitsLoss`는 입력값의 자료형이 실수여야 한다.
- 딥러닝 기초4-4
  - 다중 분류는 출력 차원이 분류하고자 하는 클래스의 수와 같다.
  - 다중 분류의 출력층에서는 softmax가 사용된다.
  - softmax는 각 logit의 비율대로 모든 값의 합이 1이 되도록 만들어준다.
  - 그 중에서 가장 큰 값이 예측된 클래스이고, logit상태와 softmax후의 상태 전부에서 `argmax`를 통해서 에측 클래스를 찾을 수 있다.
  - 다중 분류에서는 `CorssEntropyLoss`를 손실 함수로 사용하며, 이진 분류와 마찬가지로 내무적으로 softmax를 진행하기 때문에 logit상태 그대로 넘겨준다.
  - softmax를 진행한 결과를 입력하면 두 번 처리하게 된다.
  - softmax를 진행할 때에는 `dim`을 설정할 수 있는데, softmax를 진행하고자 하는 차원을 고르는 것이다.
  - 이는 `axis`와 비슷한 역할이다.

## 왜 중요한가
- 딥러닝에서의 비선형성을 구성하는 중요한 요소인 활성화 함수에 대한 내용이기 때문에 중요하다.
- 활성화 함수 없이는 비선형 예측이 불가능하기 때문에 중요하다.
- 또한 문제의 유형에 따라서 사용하는 손실함수와 출력 활성 함수 등을 구분할 수 있다.

## 코드/예시
```python
# 여러 층을 구성하지만 단일 아핀 변환과 같은 예제
import torch
import torch.nn as nn

# 결과를 재현하기 위해 seed를 고정합니다.
torch.manual_seed(0)

# 샘플 5개, feature 3개를 가진 입력 Tensor입니다.
x = torch.randn(5, 3)

# 활성화 함수 없이 Linear만 두 개 쌓은 모델입니다.
model_without_activation = nn.Sequential(
    nn.Linear(3, 4),  # feature 3개 -> feature 4개
    nn.Linear(4, 2)   # feature 4개 -> feature 2개
)

out = model_without_activation(x)

print("input shape :", x.shape)
print("output shape:", out.shape)
```
```python
# ReLU 동작을 확인하는 예제
import torch
import torch.nn as nn

# 음수, 0, 양수가 섞인 Tensor입니다.
x = torch.tensor([-3.0, -1.0, 0.0, 2.0, 5.0])

# ReLU layer를 만듭니다.
relu = nn.ReLU()

# ReLU를 적용합니다.
y = relu(x)

print("x:", x)
print("y:", y)
print("x shape:", x.shape)
print("y shape:", y.shape)
```
```python
# sigmoid 동작 확인 예제
import torch

logits = torch.tensor([-5.0, 0.0, 5.0])
probs = torch.sigmoid(logits)

print("logits:", logits)
print("probs :", probs)
```
```python
# BCEWithLogitsLoss 사용 예제
import torch
import torch.nn as nn

model = BinaryMLP()
criterion = nn.BCEWithLogitsLoss()

# 샘플 8개, feature 4개입니다.
x = torch.randn(8, 4)

# target도 logits와 같은 shape로 맞춥니다.
# 이진 분류 target은 보통 float 타입을 사용합니다.
target = torch.tensor([
    [0.0],
    [1.0],
    [0.0],
    [1.0],
    [1.0],
    [0.0],
    [1.0],
    [0.0]
])

logits = model(x)
loss = criterion(logits, target)

print("logits shape:", logits.shape)
print("target shape:", target.shape)
print("loss:", loss)
```
```python
# softmax 동작 확인 예제
import torch

logits = torch.tensor([[2.0, 0.5, -1.0, 1.2]])
probs = torch.softmax(logits, dim=1)

print("logits:", logits)
print("probs :", probs)
print("sum   :", probs.sum(dim=1))
```
```python
# CrossEntropyLoss동작 확인 예제
import torch
import torch.nn as nn

model = MultiClassMLP(input_dim=4, hidden_dim=16, num_classes=3)
criterion = nn.CrossEntropyLoss()

x = torch.randn(8, 4)

# target은 one-hot이 아니라 class index입니다.
# class가 3개라면 가능한 값은 0, 1, 2입니다.
target = torch.tensor([0, 1, 2, 1, 0, 2, 1, 0], dtype=torch.long)

logits = model(x)
loss = criterion(logits, target)

print("logits shape:", logits.shape)
print("target shape:", target.shape)
print("target dtype:", target.dtype)
print("loss:", loss)
```
