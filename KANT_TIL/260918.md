# 2026-09-18 TIL

## 오늘 한 것
- 프로젝트 README의 최종 정제 및 완성을 했다.
- 플로우차트/다이어그램들에 대한 최종 검토 및 확정을 진행했다.
- 팀 발표를 진행했다.
- 팀 발표에서는 클라우드 모델과 로컬 모델의 비교 결과에 대해서 발표를 담당했다.
- 여러 팀들과 얘기나누면서 피드백을 주고받았다.

## 왜 중요한가
- 발표도 중요한 과정 중 하나기 때문에 중요하다.

## 코드/예시
```mermaid
flowchart TD
    load_q[0. 문항 세트 로드]
    check_model[1. 현재 떠있는 모델 확인]
    unload[2. 전부 언로드]

    subgraph cold[3. Cold 요청 - 에이전트별 모델 반복]
        cold_request["Cold 요청(모델별 최초 로드)"]
        cold_load_duration(cold_load_duration)
        cold_prompt_eval_duration(cold_prompt_eval_duration)
        cold_eval_duration(cold_eval_duration)
        cold_request -.-|측정| cold_load_duration
        cold_request -.-|측정| cold_prompt_eval_duration
        cold_request -.-|측정| cold_eval_duration
    end

    subgraph model_info[4. 모델 기본 설정 확인 - 에이전트별 모델 반복]
        loaded_model[로드된 모델]
        digest(digest)
        quantization_level(quantization_level)
        max_context_length(max_context_length)
        use_context_length(use_context_length)
        loaded_model -.-|확인| digest
        loaded_model -.-|확인| quantization_level
        loaded_model -.-|확인| max_context_length
        loaded_model -.-|확인| use_context_length
    end

    subgraph pipeline[5. Pipeline 실행 - Analyzer to Solver to Critic]
        analyzer["Analyzer 호출<br/>(질문 분석)"]
        solver["Solver 호출<br/>(Analyzer 결과 참고, 답변 생성)"]
        critic["Critic 호출<br/>(Solver 답변 검증/수정, 최종 답변)"]
        metrics["단계별 metrics<br/>(total_time, gen_speed,<br/>prompt_speed, VRAM_usage,<br/>load_duration, wall_time)"]

        analyzer -->|analysis| solver
        solver -->|solution| critic
        analyzer -.-|기록| metrics
        solver -.-|기록| metrics
        critic -.-|기록| metrics
    end

    aggregate[6. 문항별 결과 집계 및 저장<br/>summarize + save_result]
    final[7. 전체 반복 종료 후 최종 요약 저장]

    load_q --> check_model
    check_model --> unload
    unload --> cold
    cold --> model_info
    model_info --> pipeline
    pipeline --> aggregate
    aggregate -.->|질문 세트 전체에 대해<br/>REPEAT_COUNT회 반복| pipeline
    aggregate --> final
```
